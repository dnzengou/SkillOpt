## EXECUTIVE SUMMARY

Clow is the **marketplace layer** atop the exploding Claw AI agent ecosystem (OpenClaw: 215k+ GitHub stars in 6 weeks). Positioning: not another agent — the **agent economy** where PicoClaw bots are discovered, deployed, and **evolved**. First-mover advantage window: ~90 days before OpenClaw ships a native registry.

**EvoMetaClaw** is the uncopiable moat: SkillOpt's self-improving skill paradigm (arXiv:2605.23904) applied to Clow bots. Every conversation = training step. Every weekly epoch = smarter bot. OpenClaw can build a registry; they cannot build self-evolving bots without SkillOpt + Clow's trajectory data flywheel.

**Strategy:** Seed (organic GitHub + X + EvoMetaClaw reveal) → Activate (onboarding + community) → Monetize (Pro with EvoMetaClaw gated) → Scale (developer program + enterprise SkillOpt on-prem).

### Rl — Reliabilify (Forecast & Pipeline Health)

**Forecast model (bottom-up):**
```
Month 1: 300 signups × 0% conversion  = MRR $0
Month 2: 800 signups × 2% conversion  = 16 Pro × $9 = MRR $144
Month 3: 1,500 total × 3.5%           = 53 Pro × $9 = MRR $477
Month 4: 2,500 total × 4.5% + Teams   = 112 Pro + 8 Teams = MRR $1,240
Month 6: 6,000 total × 5% + Teams     = 300 Pro + 25 Teams = MRR $3,425
```

**Confidence intervals:**
- Pessimistic (PH launch flops): 50% of base → MRR $1,700 at Month 6
- Base: MRR $3,425 at Month 6
- Optimistic (EvoMetaClaw goes viral): 2× base → MRR $6,850 at Month 6

**Quality gates:**
- [ ] Weekly pipeline review: signups, activation, conversion
- [ ] Alert: if Week 2 signups < 50 → pivot PH launch date or messaging
- [ ] Forecast error target: ±20% (early stage tolerance)

### So — Solidify (Unit Economics)

| Metric | Value | Gate |
|--------|-------|------|
| CAC (organic) | ~$0 | Maintain organic-first through Month 3 |
| CAC (if paid) | <$15 target | LTV:CAC must stay >3× |
| ARPU (Pro) | $9/mo | — |
| LTV (Pro, 12mo avg) | ~$108 | Assumes 30% annual churn |
| LTV:CAC (organic) | >10× | ✅ |
| EvoMetaClaw COGS | ~$0.10/evolution | 4 evolutions/mo = $0.40 → 95% gross margin |
| Payback period | <2 months (organic) | Target <6 months even with paid CAC |
| NRR target | >110% | EvoMetaClaw drives expansion (Free→Pro on 100 conversations) |

**Stress test (±20% scenarios):**
- CAC +20% (paid needed): LTV:CAC = 7.2× — still healthy
- Churn +20% (50% annual): LTV = $81 — payback still <2mo at $0 CAC
- ARPU -20% ($7 early bird persists): MRR Month 6 = $2,940 — acceptable

### St — Stabilize (Continuity + Reputation)

**Critical processes:**
1. Bot registry availability (uptime >99.9% — Vercel handles this)
2. EvoMetaClaw evolution jobs (async — failure = skip, not crash)
3. X/Twitter content pipeline (Buffer queue — 2-week buffer maintained)
4. Stripe billing (Stripe handles; dunning auto-configured)

**Reputation risks:**
- Bot evolves in harmful direction → hard gate: no skill deployed without human review in v0.x
- PicoClaw security vulnerability → immediate notice to Clow community + patch coordination
- SkillOpt paper retracted → EvoMetaClaw still works; positioning shifts to "proprietary evolution"
